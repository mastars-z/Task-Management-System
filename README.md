# Task-Management-System
a Task Management System using pure JavaScript to strengthen JavaScript fundamentals 
###Features
  1. Create, update, and delete tasks
  2. Mark tasks as completed
  3. Filter tasks (All, Completed, Pending)
  4. Search tasks
  5. Add task priority
  6. Store data using LocalStorage
  7. Display task statistics
  8. Input validation
